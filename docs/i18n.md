# Language (ID / EN)

- Copy lives in `src/i18n/dictionary.ts` (`en` defines the shape, `id` must match). Project text lives in `src/data/projects.ts` as `{ en, id }` objects.
- Components read text with `const { t, lang } = useI18n()`.
- **Initial language**: (1) the language the visitor picked before (localStorage), else (2) English if the browser time zone is outside Indonesia (Asia/Jakarta, Pontianak, Makassar, Jayapura), else (3) Indonesian.
- Only a manual choice (ID/EN switch in the navbar) is remembered. Auto-detection is never saved.
- Region check is by time zone: no permission prompt, no network request, no third-party service. It's a heuristic (a VPN does not change it; someone travelling will get English and can switch). If exact country is needed later, Cloudflare Pages can provide the visitor country server-side.
- `<html lang>` and the page title update on every switch.
- When Sanity is added, localized fields replace the `{ en, id }` objects in `projects.ts`.

# Routing
Hash routes (work on GitHub Pages without server config): `#/about` → About page, everything else → Home (`#works`, `#contact`… are in-page anchors). See `src/hooks/useHashRoute.ts` and `App.tsx`.
